# Pakson’s Library

A family picturebook library with one permanent entrance, a felt forest home, and responsive Chinese and English bookshelves. Portrait screens show the centre of the home scene; compact landscape screens frame both language plaques and the Pakson bag. Each collection uses one complete, top-aligned bookshelf illustration that scrolls vertically.

[Open the library](https://fredericktsang0320.github.io/pakson-storybook/home.html), then choose English and a book:

- **Thank You!** — Pakson and Pikachu, 19 authored pages, five practice groups and eight questions. The approved artwork, synthetic speech and reader remain unchanged.
- **Yummy food!** — Pakson and Doraemon: The Dim Sum Adventure, 18 authored pages, four practice groups, 11 learning words and 11 questions. Doraemon, Nobita and Shizuka use original English synthetic character performances, not official voice-actor recordings.

Each real book-card tap starts from the cover and plays the cover narration immediately. Story and practice pages use the same touch-friendly reader. Narration and word spelling follow British English; each word demonstration leaves six seconds for the reader’s turn. There is no background music or page-turn sound.

The small library core updates first. A full offline save is confirmed only after every runtime file passes its SHA check. Downloads can resume; insufficient storage leaves the library usable without claiming that the whole collection is offline. When the two-book download is larger than the known storage quota, the previous complete offline copy is retained and its unchanged files remain available by verified SHA.

The permanent HOME and collection routes remain independent of retired reader entry paths. Online HOME and catalogue requests refresh from the server with an offline fallback. Unrelated applications and reading preferences are retained. If an older cached library remains visible, [refresh the library once](https://fredericktsang0320.github.io/pakson-storybook/repair-v23.html); this returns to the same HOME address.

Tap the Pakson bag on HOME for a quiet burst of rising stars. Repeated taps are bounded, and reduced-motion preferences are respected.
