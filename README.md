# Pakson’s Library

A family picturebook library at one stable URL, with a felt forest home and responsive Chinese and English bookshelves. The home uses one landscape illustration: portrait screens show the centre; landscape screens retain the whole picture. Source-coordinate links stay aligned with the pictured language plaques.

The catalogue currently contains one English book, Thank You!, with 19 authored pages, five practice groups and eight questions. Existing synthetic voices and story artwork are retained. The library home updates first. The full book downloads separately and resumes after an interruption; the reading menu confirms when all resources have been saved for offline reading. Reading progress is retained during updates.

[Open the library](https://fredericktsang0320.github.io/pakson-storybook/).

If an older cached library remains visible, [refresh the library once](https://fredericktsang0320.github.io/pakson-storybook/refresh.html). This returns to the same library address.
