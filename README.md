# Pakson's Storybook: Thank You!

A 13-page illustrated English audiobook with Pakson and Pikachu.

- Each illustration fills one complete facing-page spread.
- Tap the book to start, pause or resume the story. Tap or drag a page corner to turn the paper.
- Open the menu inside the book corner to replay, read the English transcript, adjust volume, or change music, sound effects and automatic turning.
- In Safari, choose **Share > Add to Home Screen** to open the book as a web app.
- While connected to the secure website, save the chapter for offline reading. Keep the page open until every picture and sound has been checked. Browser storage can be cleared by the browser or device.

Audio starts after your first tap. The new character voices are AI-generated with Qwen3-TTS using fixed original synthetic references. Pika calls are original VoiceDesign interpretations; only the short /d/ phonics cue uses Kokoro. See [CREDITS.md](CREDITS.md) for sound and model attribution.

This static website uses no tracking or advertising. It needs no account and serves pre-generated audio rather than requesting speech from a cloud service.
